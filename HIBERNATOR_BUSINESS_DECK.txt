SLIDE 2: THE PROBLEM
--------------------------------------------------------------------------------
THE PASSIVE TECHNICAL TALENT PARADOX
Why conventional recruiting fails for top-decile technical talent:

  [ Resumes & Buzzwords ]
  (LinkedIn / Job Boards)
           |
           v
  [ Keyword Matchers ] ────────> Zero code audit; recruiters match string tokens
           |
           v
  [ Generic InMail Spam ] ─────> "Impressed by your background at X!"
           |
           v
  [ 98% Archive / Bounce Rate ]
  Elite engineers tune out recruiter noise and ignore outreach completely.

THE THREE INDUSTRY BOTTLENECKS:
1. SHALLOW SIGNAL DETECTION:
   Conventional platforms rely on self-reported job titles and keyword stuffing
   rather than tangible code craftsmanship, commit velocity, or architectural
   depth.

2. TEMPLATE FATIGUE & LOW RESPONSE RATES:
   Top engineers receive dozens of copy-pasted recruiter messages weekly.
   Typical reply rates on InMail hover around 2% to 4%.

3. THE SOURCING ASYMMETRY:
   Founders and CTOs waste 20+ hours a week manually browsing GitHub repos,
   arXiv papers, and personal tech blogs trying to identify verified builders.

SLIDE 3: THE SOLUTION
--------------------------------------------------------------------------------
MINING DEEP TECHNICAL EXHAUST INTO ACTIONABLE TALENT SIGNALS

  [ Raw Engineering Exhaust ]
  - Public Git Commits, Code Diffs, and AST Changes
  - Merged Pull Requests & Peer Code Reviews
  - arXiv Papers & Semantic Scholar Citations
  - Engineering Blogs & daily.dev syndication
                 |
                 v
  [ Entity Resolution & Identity Graph Engine ]
  Resolves git commit emails, PGP keys, aliases, and personal domains
                 |
                 v
  [ AI Craftsmanship & Hibernation Evaluation ]
  Powered by Gemini Multimodal + pgvector 384-dimensional dense embeddings
                 |
                 v
  [ Context-Aware Autonomous Outreach ]
  Drafts hyper-personalized emails citing exact PR numbers, diffs, & impact

KEY ADVANTAGES:
* ZERO SELF-REPORTING:
  Candidates are evaluated purely on what they have engineered, reviewed, and
  shipped to production.
* AUTONOMOUS IDENTITY RESOLUTION:
  Connects anonymous GitHub handles, git commit metadata, and research author
  profiles into a single verified candidate dossier.
* HIGH-EMPATHY, CODE-SPECIFIC HOOKS:
  Outreach speaks developer-to-developer, referencing actual pull requests,
  algorithms, and performance optimizations.
